# 爱恋存档

使用 uni-app、Vue 3、TypeScript 和 Pinia 实现的微信小程序前端体验版。

## 当前页面

- 存档：首页动态、对象/自己筛选、喜欢、拥抱
- 记录：开心/难过、具体情绪、文字、补记日期、可见范围、评论开关
- 回顾：个人/对象切换、周/月/三个月、趋势图、情绪日历
- 我的：个人资料、绑定状态、设置入口
- 心情详情：互动、单层评论、本人评论编辑
- 对象绑定：邀请码、绑定规则、解绑流程
- 微信身份：通过 `uni.login` 获取临时凭证，由用户主动选择头像并确认昵称

所有数据暂存在 Pinia 内存中，刷新或重新启动后恢复为演示数据。后续接后端时可保留页面结构和领域类型，替换 Store 内的数据操作。

微信头像与昵称会暂存在微信本地缓存；头像目前仍是小程序临时文件，正式上线前需上传到后端或云存储。`uni.login` 的临时凭证也需要后端换取 OpenID 和正式会话。

## 已确认的 MVP 规则

- 每天允许发布多条记录，也允许补记过去日期
- 绑定后默认双方可见，但始终保留“仅自己可见”
- 新对象只能看到新一段关系建立后公开的内容
- 解除绑定后双方立即失去访问权；本人仍可查看过去收到的互动
- 对象可点赞、单层评论、点击一次留下拥抱
- 心情记录发布后不可编辑或删除，保留当时真实状态
- 自己发布的评论允许编辑，但不提供删除入口
- 首版不做消息中心、图片、纪念日、恋爱天数和付费能力

## 本地运行

```bash
npm install
npm run dev:mp-weixin
```

然后在 [`.env`](file:///Users/dongyuanwai/code/codex/love-archive/.env) 中填写 `VITE_MP_WEIXIN_APP_ID`，再使用微信开发者工具打开 `dist/dev/mp-weixin`。运行 `dev` 或 `build` 时，`vite.config.ts` 会把这个值同步到 `src/manifest.json` 的 `mp-weixin.appid`。

## 检查与构建

```bash
npm run type-check
npm run build:mp-weixin
```
